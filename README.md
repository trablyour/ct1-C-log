# TaskManager

Консольное приложение на .NET 8 для управления списком задач с логированием и трассировкой операций.

## Возможности

- создание, удаление и вывод списка задач (плюс отметка выполнения);
- задачи сохраняются в `data/tasks.json` и не пропадают между запусками;
- **логирование** через `Microsoft.Extensions.Logging`:
  - в консоль (уровень Information и выше, разными цветами);
  - в файл `logs/app-ГГГГММДД.log` (уровень Debug и выше);
  - у каждого события свой код (`EventId`), список в `Logging/LogEvents.cs`;
- **трассировка** через `System.Diagnostics.Trace`:
  - каждая операция пишет старт, пошаговые действия, результат и время выполнения;
  - вывод в файл `logs/trace-ГГГГММДД.log` и (по желанию) в консоль.

## Запуск

```bash
dotnet run              # интерактивное меню
dotnet run -- --demo    # автоматический демонстрационный сценарий
```

## Структура

| Папка / файл | Назначение |
|---|---|
| `Program.cs` | настройка логирования и трассировки, меню, демо-сценарий |
| `Models/TaskItem.cs` | модель задачи |
| `Services/TaskService.cs` | операции с задачами |
| `Services/TaskRepository.cs` | сохранение в JSON |
| `Logging/` | свои провайдеры логов (консоль, файл) и коды событий |
| `Tracing/OperationTrace.cs` | пошаговая трассировка операций |

## Уровни логирования

| Уровень | Когда используется |
|---|---|
| Debug | технические детали (сохранение файла) |
| Information | успешные операции: создание, удаление, вывод списка |
| Warning | ошибки пользователя: пустое название, задача не найдена, неверный ввод |
| Error | ошибки хранилища: поврежденный файл, нет доступа на запись |
| Critical | необработанное исключение |
